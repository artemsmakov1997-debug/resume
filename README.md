# Артём Шмаков — портфолио

Адаптивный статический сайт по согласованному оранжевому макету. Работает без сборки и внешних библиотек.

## Просмотр
Откройте `index.html` или запустите `python3 -m http.server 8000` в этой папке.

## Публикация на GitHub Pages
В Settings → Pages выберите Deploy from a branch → main → / (root) → Save.
Ожидаемый адрес после публикации: https://artemsmakov1997-debug.github.io/resume/

## Добавление работ
Все карточки, статьи и опыт редактируются в `content.js`. Изображения и видео размещайте в `assets/`.
- `groups`: название, изображение `image`, необязательные `description` и `url`.
- Видео: заполните `videoSrc` адресом MP4/WebM, чтобы открыть настоящий плеер. Пока показывается явно подписанная демонстрационная обложка.
- `articles`: жанр, заголовок, анонс `excerpt`, массив абзацев `paragraphs`. Для настоящего текста установите `demo: false`.
- После замены всех демонстрационных работ обновите подписи в `index.html`.
- Фото извлечено из предоставленного PDF. Обложки взяты из согласованного концепта и не выдаются за выполненные проекты.
- Резюме для скачивания: `assets/resume.pdf`.

Анонсы текстов раскрываются при наведении и фокусе. На сенсорных экранах они видны сразу. Полный текст открывается по нажатию в диалоге; закрытие — кнопкой, Escape или нажатием вне окна. Поддерживаются клавиатура и reduced motion.
